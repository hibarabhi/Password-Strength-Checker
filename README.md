# Password Strength Checker & Auditor

A command-line Python tool designed to evaluate password complexity, check against common vulnerability rules, and provide actionable security feedback.

## Features
- **Complexity Analysis:** Checks for minimum length, uppercase/lowercase letters, numbers, and special symbols.
- **Security Feedback:** Generates an overall strength rating and specific suggestions for improvement.
- **Vulnerability Screening:** Flags weak or commonly used password patterns.

## Tech Stack
- **Language:** Python
- **Tools:** Git, GitHub, Thonny
